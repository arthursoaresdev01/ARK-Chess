
# ♟️ ARK Chess

ARK Chess é um projeto em Python para estudo e treinamento de xadrez, utilizando visão computacional, reconhecimento de peças e análise de posições com Stockfish.

## 🚀 Funcionalidades

- Captura automática do tabuleiro
- Reconhecimento das peças com YOLO
- Conversão da posição para FEN
- Detecção da orientação do tabuleiro
- Acompanhamento dos movimentos
- Recuperação de sincronização
- Análise com Stockfish
- Exibição das 3 melhores jogadas

## 🧠 Tecnologias

- Python
- OpenCV
- MSS
- Ultralytics / YOLO
- python-chess
- Stockfish

## ⚙️ Fluxo

Captura da tela → reconhecimento das peças → geração do FEN → validação → Stockfish → sugestões.

## ⚠️ Uso

Projeto destinado a estudo, análise e treinamento contra bots.
